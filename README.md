# COS 201 - Computer Programming I (Week 3)

This repository contains three simple Java programs.

## Programs

1. **SimpleCalculator.java** - Takes two numbers and an operator (+, -, *, /) and prints the result.
2. **AverageCalculator.java** - Asks how many numbers you want, reads them, and prints their sum and average.
3. **ItemCost.java** - Takes an item name, price and quantity, and prints the total cost.

## Requirements

- Java Development Kit (JDK) 8 or higher installed.
- Check with: `java -version` and `javac -version`

## How to Compile and Run

Open a terminal in the folder containing the files, then run:

```
javac SimpleCalculator.java
java SimpleCalculator

javac AverageCalculator.java
java AverageCalculator

javac ItemCost.java
java ItemCost
```

## Sample Run (SimpleCalculator)

```
Enter first number: 10
Enter an operator (+, -, *, /): *
Enter second number: 5
10.0 * 5.0 = 50.0
```
